# 💑 우리 가계부

망후와 예랑고가 함께 사용하는 우리네 가계부 웹앱이에요.
수입과 지출을 함께 기록하고, 월별 통계와 예산 관리까지 할 수 있어요.

---

## 🚀 시작하기

### 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

브라우저에서 `http://localhost:5173` 으로 접속하세요.

### 환경변수 설정

프로젝트 루트에 `.env.local` 파일을 만들고 Supabase 정보를 입력하세요.

```
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_anon_key
```

---

## 📖 사용 방법

### 1단계 — 회원가입 & 로그인

1. `http://localhost:5173` 접속 → 로그인 페이지로 이동돼요.
2. **"회원가입"** 링크를 눌러 이메일과 비밀번호로 계정을 만드세요.
3. 가입 후 로그인하면 **설정 페이지**로 자동 이동해요.

> **참고:** Supabase 이메일 인증이 켜져 있으면 로그인 시 `Email not confirmed` 오류가 나요.
> Supabase 대시보드 → Authentication → Providers → Email → **Confirm email 비활성화**로 해결할 수 있어요.

---

### 2단계 — 커플 연결하기

가계부를 함께 쓰려면 먼저 커플 방을 만들어야 해요.

#### 방 만드는 사람 (파트너 A)

1. 설정 페이지에서 **닉네임** 입력
2. **"새 방 만들기"** 버튼 클릭
3. 생성된 **8자리 초대 코드**를 파트너에게 공유하세요

#### 참여하는 사람 (파트너 B)

1. 회원가입 후 설정 페이지에서 **닉네임** 입력
2. 받은 **초대 코드** 입력
3. **"코드로 참여하기"** 버튼 클릭

연결이 완료되면 두 사람의 모든 거래 내역이 실시간으로 공유돼요.

---

### 3단계 — 거래 기록하기

#### 거래 추가

- **대시보드** 또는 **거래 내역** 페이지의 **"+ 추가"** 버튼을 눌러요.
- 아래 정보를 입력하고 저장하세요.

| 항목 | 설명 |
|------|------|
| 유형 | 수입 / 지출 선택 |
| 금액 | 금액 입력 |
| 카테고리 | 식비, 교통, 데이트 등 선택 |
| 날짜 | 거래 날짜 선택 |
| 메모 | 내용 간단히 메모 (선택) |

#### 지출 카테고리
🍽️ 식비 / 🚌 교통 / 🛍️ 쇼핑 / 🎬 문화·여가 / 💊 의료·건강 / 🏠 주거·공과금 / 💑 데이트 / 📦 기타

#### 수입 카테고리
💰 급여 / 💵 부수입 / 🎁 용돈·선물 / 📦 기타

#### 거래 수정 / 삭제
- **거래 내역** 페이지에서 각 항목을 눌러 수정하거나 삭제할 수 있어요.

---

### 4단계 — 월별 통계 보기

**통계** 페이지에서 월을 선택하면 아래 차트를 확인할 수 있어요.

- **수입 / 지출 막대 차트** — 이번 달 수입과 지출 한눈에 비교
- **카테고리별 파이 차트** — 어디에 가장 많이 썼는지 확인
- **일별 지출 추이 꺾은선 차트** — 날짜별 지출 흐름 파악

---

### 5단계 — 예산 관리하기

**예산** 페이지에서 이번 달 예산을 설정할 수 있어요.

- **전체 예산** 설정 → 대시보드에 진행률 바로 표시
- **카테고리별 예산** 설정 → 식비, 데이트 등 항목별로 관리
- 예산을 초과하면 진행률 바가 빨간색으로 표시돼요
